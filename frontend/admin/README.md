# Telegram Access Control — README

A small FastAPI app to manage access to a service by Telegram user ID.  
Features: store Telegram users in PostgreSQL, admin CRUD API + simple web admin UI (Jinja2 + Bootstrap), JWT admin auth and cookie-based admin UI login, Alembic migrations.

## Quick links

### Swagger / OpenAPI
http://127.0.0.1:8000/docs

### Admin UI (login)
http://127.0.0.1:8000/admin-ui/login

### Public access check
GET /public/access/{telegram_user_id}

## 1 — Install & run locally (venv)

### Windows example (PowerShell / CMD)

```bash
# create venv (if you don't have one)
python -m venv venv

# activate venv
# PowerShell
venv\Scripts\Activate

# install dependencies
pip install -r requirements.txt

# some extra packages sometimes required:
pip install python-multipart jinja2 asyncpg

```

## Run migrations and start app:
```bash
# apply alembic migrations
alembic upgrade head

# create initial admin (dev helper)
python scripts/create_admin.py

# run app
uvicorn app.main:app --reload
```
### Open http://127.0.0.1:8000/docs or http://127.0.0.1:8000/admin-ui/login.

## 3 — Database migrations

### Alembic is configured. Typical commands:
```bash 
# create new autogenerated revision (after changing models)
alembic revision --autogenerate -m "meaningful message"

# apply migrations
alembic upgrade head

# downgrade
alembic downgrade -1
```

### If Alembic complains about missing url or async engine errors, verify DATABASE_URL in .env and the alembic/env.py configuration — it must provide the URL or read settings properly.
